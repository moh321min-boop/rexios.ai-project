# Roles and Responsibilities

RexiosAI is built by an open community.
Roles are defined by tasks, not by fixed positions.
Anyone with the right skill can contribute to any area.

This document describes the main roles, what each role does, and how
contributors are organized.

---

## 1. How the Team Works

There are two levels of participation.

### Core Team

- Selected from the community.
- Has direct write access to the `main` branch.
- Reviews Pull Requests from external contributors.
- Each member is responsible for one or more areas.
- Membership is based on contribution, not on title.
- The Project Maintainer confirms Core Team membership.

### External Contributors

- Anyone from the public.
- Contributes through Pull Requests.
- Can propose ideas, fix documentation, or add new content.
- May be invited to the Core Team based on consistent contribution.

---

## 2. Main Roles

Roles are grouped by area.
A single person can hold more than one role.
Roles may change over time based on project needs.

### Project Maintainer

- Owns the overall vision and direction.
- Coordinates between roles.
- Approves major changes.
- Manages the repository structure.
- Confirms Core Team membership.
- Decides when a phase is complete.

### Documentation Lead

- Maintains all documentation files.
- Ensures consistency across documents.
- Reviews documentation Pull Requests.
- Keeps `README.md`, `ROLES.md`, `STACK.md`, and `CONTRIBUTING.md` up to date.
- Currently shared with the Project Maintainer until a dedicated lead is assigned.

### Frontend Developer

- Builds user interfaces.
- Works on pages, forms, and dashboards.
- Ensures responsive and accessible design.
- Collaborates with the Designer and Backend Developer.

### Backend Developer

- Builds APIs and server logic.
- Manages authentication, data models, and integrations.
- Handles file uploads and GitHub linking.
- Collaborates with the AI / ML Engineer.

### AI / ML Engineer

- Builds the AI analysis pipeline.
- Handles document ingestion and text extraction.
- Implements matching logic.
- Improves the experience using AI.

### Designer

- Creates the design system.
- Designs screens and user flows.
- Ensures a clean and consistent look.
- Works closely with the Frontend Developer.

### Community Manager (Optional)

- Welcomes new contributors.
- Helps new members find tasks.
- Organizes discussions and updates.
- Keeps the community active and respectful.

---

## 3. How Roles Are Assigned

- Roles are assigned by task, not by person.
- Anyone can take a task if they have the skill.
- The Project Maintainer confirms role assignments.
- Roles can change over time based on needs.
- A person may hold more than one role.

---

## 4. Contribution Path

1. Join as an external contributor.
2. Contribute consistently through Pull Requests.
3. Get invited to the Core Team by the Project Maintainer.
4. Take responsibility for a specific role or area.
